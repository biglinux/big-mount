# History: Big-Mount 2.0 – 2.6

These documents describe Big-Mount while it also carried a drive manager,
diagnosis, safe removal, file rescue and Secure Erase. They are kept unchanged
as the record of the decisions behind the automount (02 device detection, 03
filesystem support, 08 performance, 12 field report) and of the work that is
now [Big Storage Rescue](https://github.com/biglinux/big-storage-rescue), which
keeps the same documents in its `docs/big-mount-history`.
